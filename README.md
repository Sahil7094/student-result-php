# Student Result Management System

A simple web-based mini project that allows users to enter a roll number and view the corresponding student result.

## Description
This project is a basic result lookup system built as a mini project.  
Users can enter a roll number, and the system fetches and displays the stored result from the database.

## Features
- Enter roll number to view result
- Result fetched dynamically from database
- Simple and clean user interface
- Lightweight and easy to use

## Tech Stack
- Backend: PHP
- Database: MySQL
- Frontend: HTML, CSS

## How It Works
1. User enters a roll number
2. Backend validates the input
3. Result is fetched from the database
4. Result is displayed on the web page
